Watch Value Tracker

A small Flask web app that tracks the market price of luxury watches over time. Browse a table of watches, open a detail page with key statistics and a price chart, and simulate how a past purchase would have performed.

Features
Home page: a table of all watches with their current price and their variation over 12 months and since the first month, shown in green when positive and in red otherwise.
Detail page (/watch/<slug>): current, minimum and maximum price, 12 month variation, variation since the first month, premium over the retail price, annualised volatility, and a price history chart.
Performance calculator (/simulate): pick a watch, a purchase month and the price you paid. The app compares it with the market price of that month and shows your gain or loss and your return.
Prices are formatted with thousands separators and invalid input is handled with an error message.
Statistics

All statistics are computed in compute_stats(history) from the monthly price history of one watch.

Statistic	Definition
Current price	Last price of the history
Min and max price	Lowest and highest price of the period
12 month variation	(last price - price 12 months earlier) / price 12 months earlier * 100. Not available when the history has fewer than 13 months.
Variation since the first month	Same formula, against the first price of the history
Premium	Current price against the retail price, in percent. Positive when the watch resells above its new price.
Annualised volatility	Standard deviation of monthly returns multiplied by the square root of 12, in percent

All percentages are rounded to one decimal.

Getting started
bash
git clone https://github.com/Lucascode-git/Projet-Watch-Value-Tracker.git
cd Projet-Watch-Value-Tracker
git switch v2

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

flask run

Then open the address printed in the terminal (by default http://127.0.0.1:5000). To use another port, run flask run --port 5001.

Data

The prices in watchprices.csv are simulated, they are not real market quotes. The file contains one row per watch and per month, with the columns used by the app: slug, brand, model, reference, date, price and retail_price. The script simu.py generates it.

Deployment

The app is deployed on Render as a Web Service.

Build command: pip install -r requirements.txt
Start command: gunicorn app:app
